Why it is not run
-----------------
The J-008 execution host is Windows 11 x64 with WSL2 and Docker. Neither can
produce evidence for a macOS target: a cross-compiled Mach-O is not a native
execution record (contract section 8 rule 4) and a container run is not runtime
evidence for any native target (rule 5). The recipe refuses to run off a Darwin
host and prints a NOT_RUN record with exit 4, so an off-platform cross-compile can
never be mistaken for macOS evidence. The target stays in the
`design-complete-test-later` tier and is never presented as finish-first.

The recipe's architecture guarantee is covered by a static guard in
`tests/linux_distribution.rs` (`--arch` is required, both `aarch64-apple-darwin`
and `x86_64-apple-darwin` triples exist, every artifact records its `arch`, and
the Mach-O `cputype` is checked back against `--arch`).
