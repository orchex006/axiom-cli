     '* text=auto' with eol=lf only for md/json/yaml/yml/toml/py/rs/sh. There is NO eol=lf for *.txt, so a fresh
     checkout rewrites every evidence .txt to CRLF while the committed blob stays LF. Every size and sha256 here
     is therefore the LF-normalised value = exactly the bytes git stores (`git cat-file blob HEAD:<path>`), and every
     tracked row was cross-checked against its blob before this file was written. Verify with git, not with a raw
     hash of a freshly checked-out .txt file. Cargo.lock and *.ps1 are in the same class: CRLF in the worktree, LF in the blob.
