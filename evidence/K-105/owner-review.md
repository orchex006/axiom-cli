Compatibility and rollback: the installed CLI reports `already-installed` on rerun, and the runtime reports `already_current`. Failure from a fresh state removes only newly owned entrypoints/runtime and engine-owned activation; user content remains. Engine uninstall leaves an owned skills manifest and empty directories; the wrapper removes the manifest only when its hash still matches the pre-uninstall pointer, then prunes only directories declared by that manifest. A human edit prevents cleanup and remains intact. A complete uninstall removes the LaunchAgent, active entrypoints and runtime pointer while retaining user data and bindings.
